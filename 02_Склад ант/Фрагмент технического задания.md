Фрагмент технического задания
Процесс «Поступление материалов на склад»

1.	Цель:
Автоматизировать процесс регистрации поступления материалов от поставщиков, обеспечить корректное увеличение остатков и формирование первичных документов.

2.	Область применения:
ИС складского учёта «Склад АНТ-3». Процесс выполняется кладовщиком при приёмке товара от поставщика.

3.	Участники процесса

Роль | Действие
Кладовщик | Принимает товар, создает документ поступления
Представитель поставщика | Передает товар и накладную
Система	| Проверяет данные, проводит документ, увеличивает остатки

4.	Функциональные требования
FR-01. Система должна предоставлять форму создания документа «Поступление материалов».
FR-02. Форма должна содержать поля:
Дата (обязательное) 
Поставщик (выбор из справочника, обязательное) 
Ответственный (выбор из справочника сотрудников, обязательное) Табличная часть: материал, количество, цена, сумма
FR-03. Система должна автоматически рассчитывать сумму по строке: Сумма = Количество × Цена.
FR-04. Система должна проверять, что количество > 0 и цена ≥ 0.
FR-05. При проведении документа система должна увеличивать остатки материалов в регистре «ОстаткиМатериалов».
FR-06. При отмене проведения документа система должна удалять движения из регистра.
FR-07. Система должна сохранять историю изменений документа.

5.	Нефункциональные требования
NFR-01. Время отклика формы — не более 2 секунд.
NFR-02. Одновременная работа — не менее 5 пользователей.
NFR-03. Разграничение прав: кладовщик может создавать и проводить документы, но не удалять.
NFR-04. Данные хранятся в PostgreSQL 18.

6.	Сценарий использования 
Кладовщик открывает раздел «Поступление материалов». 
Нажимает «Создать». 
Заполняет шапку: дата, поставщик, ответственный. 
Добавляет строки: материал, количество, цена. 
Система автоматически считает сумму по каждой строке. 
Кладовщик нажимает «Провести». 
Система проверяет корректность данных. 
Система создаёт движения в регистре (приход). 
Остатки материалов увеличиваются. 
Документ получает статус «Проведён».

7. Обработка ошибок

Ситуация | Реакция системы
Не заполнено обязательное поле | Сообщение «Заполните поле Х»
Количество <= 0	| Сообщение «Количество должно быть больше 0»
Цена < 0 | Сообщение «Цена не может быть отрицательной»
Нет строк в табличной части | Сообщение «Добавьте хотя бы одну строку»
