1.	Задача проекта

Разработка ИС для автоматизации складского учета материалов:
приемка, хранение, выдача, отчетность

2.	Пробела ведения учета

Частичная автоматизация: 1С + excel + бумажные журнаы. 
Проблемы: Дублирование учета, задержки передачи данных, ошибки ручного переноса, отсутствие учета мест хранения

3.	Исправления 

Составила паспорт объекта информатизации (инфраструктура, ресурсы, 6 ролей)

Проанализировала 3 бизнес-процесса: поступление, выдача, отчёт

Построила BPMN-диаграммы для каждого процесса

Спроектировала ER-диаграмму БД (11 таблиц, связи 1:N, составные ключи)

Реализовала БД в PostgreSQL 18: создание таблиц, ограничения, тестовые данные

Написала 9 SQL-запросов (остатки, оборотная ведомость, Top-5, движения)

Создала конфигурацию в 1С: 4 справочника, 3 документа, регистр, 2 отчёта

Настроила администрирование: пользователь, GRANT, pg_dump, восстановление

Провела тестирование, исправила ошибку с отрицательными остатками

4.	Артефакты

Диаграммы

SQL

Скриншоты 1С

ТЗ-фрагмент

5.	Инструменты: PostgresSQL 18, pgAdmin, PyCharm, 1С:Предприятие 8.3, MS Visio

6.	Результат – Работающая модель ИС с интеграцией 1С + PostgresSQL, защищена на «отлично»
